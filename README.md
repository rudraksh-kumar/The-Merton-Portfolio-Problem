## How to run

```
pip install -r requirements.txt
cd src
python run_all.py
```

This takes about 2-4 minutes on a laptop (`python3` on macOS/Linux) and rewrites every file in `results/` and `figures/`.
Everything is seeded, so the numbers are identical on every run except the solver run times in
`part5_accuracy_runtime.csv` and `part5_summary.json`.

## Data

- **Equity:** `data/nse_tri_daily.csv` = NSE official daily Total Returns Index (dividends reinvested) for Nifty 50, Bank, IT, FMCG and Pharma, Sep-2007 to Nov-2026, downloaded from niftyindices.com (Reports > Historical Data > Total Returns Index Values, one year per query). The raw downloads are in `data/raw_nse/`; `cd src && python prep_nse_tri.py` rebuilds the CSV.
  If the file is missing, Parts 1 and 4 fall back to the earlier data: `data/nifty50_daily_github.csv` (price index, used with a constant dividend yield) and `data/tapetide_weekly_sector_indices.csv` (94 weekly closes, also used in the report as an independent check).
- **Risk-free rate:** `data/tbill_91d_auctions.csv` = RBI 91-day T-bill auction cut-off yields (weekly, 1993-2026), built from the RBI workbook by
  `cd src && python prep_rbi_tbill.py ../data/rbi_91d_tbill_auctions.xlsx ../data/tbill_91d_auctions.csv`.
  If that CSV is missing, Part 1 falls back to a constant 6.5%. `data/oecd_3m_interbank_monthly.csv` is an earlier interbank-rate proxy, kept for reference only.
